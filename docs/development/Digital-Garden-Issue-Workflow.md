# Digital Garden Issue 生成工作流

## 概述

本文档定义了 Digital Garden 每期 Issue 的标准化生成流程，基于第2期的成功实践，为后续内容创作提供可复用的工作流模板。

## 工作流阶段

### 阶段1：内容规划与素材收集

#### 1.1 确定本期主题方向

- [ ] 确定本期 Issue 的主题定位
- [ ] 规划内容板块（工具分享、知识分享、实用工具等）
- [ ] 设定内容质量标准

#### 1.2 素材收集与整理

- [ ] **工具分享板块**
  - [ ] 筛选有价值的开源工具或实用软件
  - [ ] 进行实际测试和体验
  - [ ] 截图记录使用过程和效果
  - [ ] 整理工具的核心特性和使用建议

- [ ] **知识分享板块**
  - [ ] 选择有深度的科技论文或研究报告
  - [ ] 深入阅读和理解核心观点
  - [ ] 提取关键发现和数据
  - [ ] 准备详细的知识简报文档

- [ ] **实用工具板块**
  - [ ] 更新或新增实用工具/服务
  - [ ] 验证工具的有效性和可用性
  - [ ] 整理使用说明和功能特点

#### 1.3 文件结构规划

```text
posts/issue-N/
├── issue-N.md          # 主文档
├── issue-N.html        # HTML版本
├── images/             # 图片资源
│   ├── 1.png
│   ├── 2.png
│   └── ...
├── [知识简报].md        # 详细知识分享文档
├── [知识简报].html      # 知识简报HTML版本
└── tmp/                # 草稿文件夹
    └── issue-N-draft.md
```

### 阶段2：内容创作

#### 2.1 草稿编写

- [ ] 创建 `tmp/issue-N-draft.md` 文件
- [ ] 按照板块结构编写初稿内容
- [ ] 确保每个板块都有完整的介绍、特性和使用建议
- [ ] 添加必要的图片引用和链接

#### 2.2 内容结构标准

**工具分享板块结构：**

```text
## 工具分享：[工具名称]

**简介**：[工具的简要介绍和定位]

### 核心特性
- **特性1**：[详细说明]
- **特性2**：[详细说明]
- **特性3**：[详细说明]

### 使用体验
[实际使用体验的描述]

![示例图片](./images/1.png)

### 使用建议
- [注意事项1]
- [注意事项2]
- [注意事项3]

**项目链接**：[GitHub链接或其他资源链接]
```

**知识分享板块结构：**

```text
## 知识分享：[研究主题]

### 研究背景
[研究的背景和意义]

### 主要发现
#### 发现标题1
[具体发现内容]

#### 发现标题2
[具体发现内容]

### 研究意义
[研究的重要性和影响]

**详细报告**：[知识简报链接]
**原文链接**：[原始论文链接]
```

**实用工具板块结构：**

```text
## 实用工具：[工具名称]（更新版）

### 项目简介
[工具的基本介绍]

### 功能特点
- **特点1**：[详细说明]
- **特点2**：[详细说明]

### 使用方式
[使用说明]

**工具网址**：[访问链接]
```

#### 2.3 图片处理

- [ ] 确保图片文件命名规范（1.png, 2.png 等）
- [ ] 优化图片大小和质量
- [ ] 为图片添加适当的 alt 文本
- [ ] 确保图片路径正确

### 阶段3：内容优化与编辑

#### 3.1 内容审核

- [ ] 检查内容的准确性和完整性
- [ ] 确保语言表达清晰流畅
- [ ] 验证所有链接的有效性
- [ ] 检查图片显示效果

#### 3.2 结构优化

- [ ] 统一标题层级和格式
- [ ] 优化段落结构和逻辑顺序
- [ ] 添加必要的分隔线和空行
- [ ] 确保 Markdown 语法正确

#### 3.3 最终定稿

- [ ] 将优化后的内容复制到正式的 `issue-N.md` 文件
- [ ] 进行最终校对和格式检查
- [ ] 确认所有引用和链接正确

### 阶段4：HTML 生成与样式优化

#### 4.1 HTML 结构设计

- [ ] 创建响应式的 HTML 模板
- [ ] 设计现代化的 CSS 样式
- [ ] 实现交互功能（图片放大、导航等）
- [ ] 确保移动端适配

#### 4.2 功能特性

- [ ] 添加目录导航
- [ ] 实现平滑滚动
- [ ] 添加图片模态框功能
- [ ] 实现键盘导航支持
- [ ] 添加阅读进度指示

#### 4.3 样式标准

- [ ] 使用现代化的渐变色彩方案
- [ ] 实现卡片式布局设计
- [ ] 添加悬停效果和动画
- [ ] 确保良好的可读性

### 阶段5：知识简报制作

#### 5.1 详细内容展开

- [ ] 基于主文档的知识分享板块，创建详细的知识简报
- [ ] 深入解析研究方法和发现
- [ ] 添加更多背景信息和上下文
- [ ] 提供更深入的分析和见解

#### 5.2 简报结构

```text
# [简报标题]

[引言：研究背景和重要性]

## 1. [章节标题]
[详细内容]

## 2. [章节标题]
[详细内容]

[结论和意义]
```

#### 5.3 HTML 版本生成

- [ ] 为知识简报创建对应的 HTML 版本
- [ ] 复用主文档的样式设计
- [ ] 确保导航和链接正确

### 阶段6：发布与更新

#### 6.1 文件发布

- [ ] 确认所有文件都已正确创建
- [ ] 检查文件路径和引用关系
- [ ] 更新主页面链接
- [ ] 测试所有功能正常工作

#### 6.2 导航更新

- [ ] 更新首页的 Issue 列表
- [ ] 添加新 Issue 的链接
- [ ] 更新前后期 Issue 的导航链接

#### 6.3 最终检查

- [ ] 在多个浏览器中测试显示效果
- [ ] 检查移动端显示
- [ ] 验证所有链接和功能
- [ ] 进行最终的内容校对

## 质量标准

### 内容质量

- [ ] 内容准确、有价值、有深度
- [ ] 语言表达清晰、专业、易懂
- [ ] 结构逻辑清晰、层次分明
- [ ] 引用和链接准确有效

### 技术质量

- [ ] HTML 结构语义化
- [ ] CSS 样式现代化、响应式
- [ ] JavaScript 功能稳定可靠
- [ ] 图片优化、加载快速
- [ ] 跨浏览器兼容性良好

### 用户体验

- [ ] 界面美观、现代化
- [ ] 导航清晰、易于使用
- [ ] 交互流畅、响应迅速
- [ ] 移动端体验良好
- [ ] 可访问性符合标准

## 检查清单

### 内容检查

- [ ] 本期主题明确，内容有价值
- [ ] 三个板块内容完整，质量高
- [ ] 工具经过实际测试验证
- [ ] 知识分享有深度，有见解
- [ ] 实用工具确实有用
- [ ] 所有链接有效，图片正常显示

### 技术检查

- [ ] Markdown 语法正确
- [ ] HTML 结构完整
- [ ] CSS 样式美观
- [ ] JavaScript 功能正常
- [ ] 响应式设计良好
- [ ] 性能优化到位

### 发布检查

- [ ] 文件结构正确
- [ ] 路径引用准确
- [ ] 导航链接更新
- [ ] 多浏览器测试通过
- [ ] 移动端测试通过

## 最佳实践

### 内容创作

1. **深度优先**：每个板块都要有深度，避免浅尝辄止
2. **实用导向**：确保推荐的工具和知识对读者真正有用
3. **原创见解**：在知识分享中加入自己的理解和分析
4. **持续更新**：定期更新实用工具，保持内容的新鲜度

### 技术实现

1. **模块化设计**：CSS 和 JavaScript 保持模块化，便于维护
2. **性能优化**：图片压缩、代码精简、加载优化
3. **可访问性**：确保键盘导航、屏幕阅读器支持
4. **渐进增强**：基础功能优先，增强功能渐进添加

### 用户体验设计

1. **一致性**：保持设计风格和交互方式的一致性
2. **直观性**：界面设计直观，用户能快速理解如何使用
3. **响应性**：确保在各种设备上都有良好的体验
4. **反馈性**：提供适当的视觉反馈和状态提示

## 注意事项

### 常见问题

1. **图片路径错误**：确保图片路径相对于 HTML 文件正确
2. **链接失效**：定期检查外部链接的有效性
3. **样式冲突**：避免 CSS 样式冲突和重复定义
4. **内容重复**：避免与往期内容重复，保持新鲜度

### 改进建议

1. **用户反馈**：收集读者反馈，持续改进内容质量
2. **技术升级**：定期更新技术栈，保持现代化
3. **内容扩展**：根据读者需求扩展内容类型
4. **协作流程**：建立团队协作流程，提高效率

---

*本工作流基于 Digital Garden 第2期的成功实践制定，可根据实际需要进行调整和优化。*
