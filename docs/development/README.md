# Digital Garden 开发文档

## 概述

本目录包含 Digital Garden 项目的开发相关文档，特别是基于第2期成功实践制定的 Issue 生成工作流模板。

## 文档结构

### 📋 工作流文档

#### 1. [Digital-Garden-Issue-Workflow.md](./Digital-Garden-Issue-Workflow.md)

**完整的工作流指南**

- **用途**：详细的 Issue 生成流程指南
- **内容**：6个阶段的完整工作流程，包括质量标准、检查清单和最佳实践
- **适用场景**：首次创建 Issue 或需要详细了解整个流程

#### 2. [Issue-Creation-Quick-Reference.md](./Issue-Creation-Quick-Reference.md)

**快速参考模板**

- **用途**：日常使用的快速检查清单
- **内容**：简化的检查清单、标准内容结构模板、文件结构
- **适用场景**：熟悉流程后的日常使用

#### 3. [Issue-Workflow-Diagram.md](./Issue-Workflow-Diagram.md)

**工作流程图**

- **用途**：可视化的工作流程展示
- **内容**：Mermaid 流程图、阶段说明、质量控制点、时间估算
- **适用场景**：理解整体流程和项目管理

## 使用方法

### 新用户建议流程

1. **首次使用**：阅读 `Digital-Garden-Issue-Workflow.md` 了解完整流程
2. **日常使用**：使用 `Issue-Creation-Quick-Reference.md` 作为检查清单
3. **项目管理**：参考 `Issue-Workflow-Diagram.md` 进行时间规划

### 经验用户建议流程

1. **快速开始**：直接使用 `Issue-Creation-Quick-Reference.md`
2. **遇到问题**：查阅 `Digital-Garden-Issue-Workflow.md` 的详细说明
3. **流程优化**：基于 `Issue-Workflow-Diagram.md` 调整工作流程

## 时间估算

| 阶段 | 预估时间 | 说明 |
|------|----------|------|
| 素材收集 | 2-3小时 | 工具测试、论文阅读 |
| 内容创作 | 3-4小时 | 草稿编写、结构搭建 |
| 优化编辑 | 1-2小时 | 内容校对、格式优化 |
| HTML生成 | 2-3小时 | 样式设计、功能实现 |
| 简报制作 | 1-2小时 | 内容展开、独立页面 |
| 发布更新 | 0.5-1小时 | 文件发布、链接更新 |
| **总计** | **9-15小时** | **完整 Issue 制作** |
