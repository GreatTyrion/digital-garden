# Digital Garden Issue 创建快速参考

## 快速检查清单

### 📋 内容规划

- [ ] 确定本期主题和三个板块内容
- [ ] 工具分享：测试工具，截图，写使用体验
- [ ] 知识分享：选择论文，写详细简报，提取关键发现
- [ ] 实用工具：验证工具，更新使用说明

### ✍️ 内容创作

- [ ] 创建 `tmp/issue-N-draft.md` 草稿文件
- [ ] 按标准结构编写三个板块内容
- [ ] 添加图片到 `images/` 文件夹（命名：1.png, 2.png...）
- [ ] 检查所有链接和图片路径

### 🎨 HTML 生成

- [ ] 复制草稿内容到正式 `issue-N.md` 文件
- [ ] 创建 `issue-N.html` 文件（复用现有样式）
- [ ] 更新页面标题、导航链接
- [ ] 测试图片模态框和交互功能

### 📄 知识简报

- [ ] 创建 `[主题].md` 详细简报文件
- [ ] 创建对应的 `[主题].html` 文件
- [ ] 确保内容深度和准确性

### 🚀 发布更新

- [ ] 更新首页 Issue 列表链接
- [ ] 测试所有页面和功能
- [ ] 多浏览器兼容性检查
- [ ] 移动端显示测试
