SYS 引言

Agent = 模型 + 驾驭（Harness）

在 AI 领域，我们正处于一场“诸神之战”的暴风眼。从 Claude Code 到 Codex，各大模型厂商都在疯狂卷工具、卷生态。然而，DeepSeek Harness 的横空出世，以一种近乎“降维打击”的方式重新定义了这场竞赛。

DeepSeek 提出了一个极具穿透力的哲学：如果说大模型是灵魂，或者是那匹跑得飞快的千里马，那么 Harness（意为“驾驭”或“马具”）就是让它能下地干活、能拉车、能真正解决现实问题的全套装备。在 DeepSeek 的语境里，Agent = 模型 + 驾驭（Harness）。模型负责抽象思考，而 Harness 负责将这种思考暴力接入文件系统、终端、网页和工具链。这不仅是工具的迭代，更是对 Agent 开发范式的彻底重构。

TOOL 洞察 · 插件

颠覆性哲学：“一切皆插件”的模块化极致

DeepSeek Harness 最令开发者兴奋的，是其极致的模块化理念——“一切皆插件”。我们已经忍受了太久闭源 Agent 助手的“黑盒”操作，而 Harness 将 Agent 的每一根神经、每一个器官都“乐高化”了。

在 Harness 的架构中，甚至连“画板（Painting Box）”都不是内核，而是一个可选的插件。这种裸机（Bare-bones）的设计思想，赋予了开发者前所未有的自由度：

Slot · 模型与工具

自由接入 DeepSeek V4 Pro 或任何第三方 API。

Slot · 技能 Skills

沉淀专业领域逻辑。

Slot · 存储与循环

决定 Agent 如何记忆和调度任务。

Slot · UI 与沙盒

随心所欲定制交互界面和代码运行环境。

用户无需动框架代码，仅需修改配置文件，即可将搜索引擎替换成公司内部服务，或调整 Agent 的审批策略。这种“不伤筋动骨”的定制化能力，让它成为了一个真正的开放式智能框架。

ASSIST 洞察 · 创造者

创造者模式：让 AI 实现“自我进化”

如果说标准模式是“人在用 AI”，那么“创造者模式（Creator Mode）”则是“AI 在造自己”。这不仅是让 AI 写代码，而是赋予 AI 权限去检查自身的运行状态、实验新的插件组合，甚至创造新的模式预设。

Key

这是开发者社区最震撼的亮点：AI 不再只是工具，它掌握了自己源代码和插件配置的“钥匙”。

创造者模式可以让它自己给自己加插件、加功能，彻底改写 Agent 开发方式，让 AI 实现了某种意义上的自我进化。

这种设计跳出了“人类喂饭”的旧框架。在创造者模式下，你可以命令 AI 为自己开发一个代码审计插件，或者自己改装出一个“只能读、不能写”的安全防御模式。这种 AI 参与自身工具构建的范式，正是 Agent 迈向自主化的第一步。

TOOL 洞察 · PTC

PTC 模式与 100% 缓存命中率：极致的成本与效率

为了解决传统 Agent “动作慢、费用高”的顽疾，DeepSeek 推出了 PTC（Programmatic Tool Calling，程序化工具调用）模式。

为什么 PTC 能实现近乎 100% 的缓存命中率？答案在于它对逻辑编排的极致压缩：

维度 标准模式 PTC 模式
执行逻辑 “一步一动”，每步都要等待结果再决策。 一次性生成一段 TypeScript 代码串联所有逻辑。
交互频率 多次往返调用，上下文不断堆叠膨胀。 一次性执行（One-shot），上下文消耗极少。
性能表现 响应较慢，Token 消耗具有随机性。 100% 缓存命中率，响应极快且成本极低。

实测数据：正是因为 PTC 将复杂的工具调用转化为一段静态、可预测的代码块，使得 API 缓存命中率极高。开发一个带手势识别的 3D 应用或复杂的全栈应用，Token 费用竟然不到 5 元人民币。在 DeepSeek 面前，高效与低价终于达成了和解。

USER 洞察 · 轨迹

轨迹系统：告别 Agent 的“黑盒”时代

我们已经容忍了 AI 的“黑盒”状态太久，现在 DeepSeek 终于“把灯打开了”。

DeepSeek Harness 的“轨迹（Trajectory）”面板通过清晰的色块展示了 Agent 的每一个呼吸：

白色 · 系统块

透明化展示系统提示词（System Prompt）。

蓝色 · 助手块

记录 AI 的思考逻辑与 Token 消耗。

黄色 · 工具块

审计工具调用的输入（Payload）与输出结果。

绿色 · 用户块

标记原始指令。

轨迹系统就像是 Agent 的实时日志（Log）。它让开发者能回溯每一个决策瞬间，排查每一个微小的 Bug。这种透明度不仅是为了调试，更是为了建立人机之间的底层信任。

ASSIST 实战

从 3D 游戏到全栈应用的工程化力量

DeepSeek Harness 在实战中展现了恐怖的工程化输出能力，特别是在复杂交互上：

  • 3D 交互深度：开发者在半小时内做出了“3D 竹知了”，细节令人发指——甚至连旋转时的影子映射都处理得极佳。虽然在“3D 坦克大战”等复杂交互中，目前仍存在摇杆响应度不够精准等小 Bug，但其渲染逻辑和框架完整度已属顶尖。
  • 全栈应用构建：“AI PPT 生成器”不仅布局优雅，更展现了其处理后端调用与前端实时预览的协同能力。
  • 生态交互优势：区别于 Codex 等传统的桌面 APP 模式，Harness 采用 WebUI 架构。这意味着它具备天然的远程访问基因，你甚至可以在手机上通过 Web 界面操控远端服务器上的 Agent 任务，甚至让 Codex 这种其他 AI 助手来反向调用 Harness。
SYS 结语

谁将控制未来的 Agent 生态？

DeepSeek Harness 发布不到 24 小时，GitHub Star 数便狂飙至 111K，这不仅仅是流量的狂欢，更是开发者对“Agent 基础设施”的一次集体投票。

DeepSeek 的野心昭然若揭：它不只想做一个编程助手，它想成为 Agent 界的“安卓系统”。当底层的模型能力逐渐抹平，真正的胜负手在于谁能提供最开放、最灵活、成本最低的“驾驭（Harness）”环境。

当 Agent 的基础设施完全开源且插件化后，未来的 AI 应用是否会因为每个人的极致定制而变得完全不同？决定 Agent 强弱的，究竟是模型参数，还是你对“驾驭”的理解？
